# 数组元素的目标和

## 题目描述

给定两个升序排序的有序数组 A 和 B，以及一个目标值 x。

数组下标从 0 开始。

请你求出满足 A[i] + B[j] = x 的数对 (i, j)。

数据保证有唯一解。

## 输入格式

第一行包含三个整数 n，m，x，分别表示 A 的长度，B 的长度以及目标值 x。

第二行包含 n 个整数，表示数组 A。

第三行包含 m 个整数，表示数组 B。

## 输出格式

共一行，包含两个整数 i 和 j。

## 数据范围

数组长度不超过 10^5。同一数组内元素各不相同。1 ≤ 数组元素 ≤ 10^9

## 输入样例

```
4 5 6
1 2 4 7
3 4 6 8 9
```

## 输出样例

```
1 1
```

## 思路

双指针：

- i 从 A 头部开始，j 从 B 尾部开始
- A[i] + B[j] > x 则 j--（B 是升序，减小和）
- A[i] + B[j] < x 则 i++（A 是升序，增大和）
- 相等则找到答案

利用有序性，时间复杂度 O(n + m)。

## 参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
const int N = 1e5 + 10;
int n, m, x;
int a[N], b[N];

int main()
{
    cin >> n >> m >> x;
    for(int i = 0; i < n; i ++ ) cin >> a[i];
    for(int j = 0; j < m; j ++ ) cin >> b[j];
    
    for(int i = 0, j = m - 1; i < n; i ++ )
    {
        while(j && a[i] + b[j] > x) j -- ;
        if(a[i] + b[j] == x)
        {
            cout << i << ' ' << j << endl;
            break;
        }
    }
    return 0;
}
```
