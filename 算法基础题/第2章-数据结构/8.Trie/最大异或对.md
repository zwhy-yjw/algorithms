# 最大异或对

## 题目描述

在给定的 N 个整数 A1，A2……AN 中选出两个进行 xor（异或）运算，得到的结果最大是多少？

## 输入格式

第一行输入一个整数 N。

第二行输入 N 个整数 A1～AN。

## 输出格式

输出一个整数表示答案。

## 数据范围

1 ≤ N ≤ 10^5

0 ≤ Ai < 2^31

## 输入样例

```
3
1 2 3
```

## 输出样例

```
3
```

## 思路

用 **Trie（字典树）+ 贪心**：

- 把所有数按二进制位（从高位 30 到低位 0）插入 Trie
- 对每个数 x，在 Trie 中**优先走与 x 当前位相反的分支**（异或得 1），这样得到与 x 异或最大的数
- 贪心正确性：高位异或为 1 一定优于低位，所以从高位到低位贪心选择相反位

- `son[M][2]`：Trie 节点，每个节点 2 个孩子（0/1）
- `idx`：节点编号

查询时：
- `if(son[p][!u])` 存在相反分支 → 走它，res 累积该位
- 否则走相同分支

时间复杂度 O(N × 31)。

## 参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
const int N = 1e5 + 10, M = 31 * N;

int n;
int a[N], idx;
int son[M][2];

void insert(int x)
{
    int p = 0;
    for(int i = 30; i >= 0; i -- )
    {
        int u = x >> i & 1;
        if(!son[p][u]) son[p][u] = ++ idx;
        p = son[p][u];
    }
}

int query(int x)
{
    int p = 0, res = 0;
    for(int i= 30; i >= 0; i -- )
    {
        int u = x >> i & 1;
        if(son[p][!u])
        {
            p = son[p][!u];
            res = res * 2 + !u;
        }
        else
        {
            p = son[p][u];
            res = res * 2 + u;
        }
    }
    return res;
}

int main()
{
    cin >> n;
    for(int i = 0; i < n; i ++ ) cin >> a[i];
    
    int res = 0;
    for(int i = 0; i < n; i ++ ) 
    {
        insert(a[i]);
        int t = query(a[i]);
        res = max(res, a[i] ^ t);
        
    }
    cout << res << endl;
    return 0;
}
```
