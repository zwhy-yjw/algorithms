# 最长上升子序列

## 题目描述

给定一个长度为 N 的数列，求数值严格单调递增的子序列的长度最长是多少。

## 输入格式

第一行包含整数 N。

第二行包含 N 个整数，表示完整序列。

## 输出格式

输出一个整数，表示最大长度。

## 数据范围

1 ≤ N ≤ 1000

−10^9 ≤ 数列中的数 ≤ 10^9

## 输入样例

```
7
3 1 2 1 8 5 6
```

## 输出样例

```
4
```

## 思路

最长上升子序列（LIS，O(n²)）：

- `f[i]`：以 a[i] 结尾的最长上升子序列长度
- 转移：`f[i] = max(f[j] + 1)`，其中 j < i 且 a[j] < a[i]
- 答案：所有 f[i] 的最大值

时间复杂度 O(n²)。数据范围大时可用贪心+二分优化到 O(n log n)。

## 参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
const int N = 1010;

int n;
int a[N], f[N];

int main()
{
    cin >> n;
    for(int i = 1; i <= n; i ++ ) cin >> a[i];
    
    for(int i = 1; i <= n; i ++ )   
    {
        f[i] = 1;
        for(int j = 1; j < i; j ++ )
            if(a[j] < a[i]) 
                f[i] = max(f[i], f[j] + 1);
    }
    
    int res;
    for(int i = 1; i <= n; i ++ ) res = max(res, f[i]);
    
    cout << res << endl;
    return 0;
}
```
