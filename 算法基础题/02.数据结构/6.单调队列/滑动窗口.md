# 滑动窗口

## 题目描述

给定一个大小为 n ≤ 10^6 的数组。

有一个大小为 k 的滑动窗口，它从数组的最左边移动到最右边。

你只能在窗口中看到 k 个数字。

每次滑动窗口向右移动一个位置。

以下是一个例子：

该数组为 `[1 3 -1 -3 5 3 6 7]`，k 为 3。

你的任务是确定滑动窗口位于每个位置时，窗口中的最大值和最小值。

## 输入格式

输入包含两行。

第一行包含两个整数 n 和 k，分别代表数组长度和滑动窗口的长度。

第二行有 n 个整数，代表数组的具体数值。

## 输出格式

输出包含两个。

第一行输出，从左至右，每个位置滑动窗口中的最小值。

第二行输出，从左至右，每个位置滑动窗口中的最大值。

## 数据范围

1 ≤ k ≤ n ≤ 10^6

## 输入样例

```
8 3
1 3 -1 -3 5 3 6 7
```

## 输出样例

```
-1 -3 -3 -3 3 3
3 3 5 5 6 7
```

## 思路

用**单调队列**维护窗口内的最值：

- `q[]` 存的是数组下标（不是值）
- `hh` 队头、`tt` 队尾

求最小值：
- 队头过期（`q[hh] < i - k + 1`）则出队
- 队尾元素 ≥ 当前值则出队（维护单调递增队列，队头即最小值）
- 当 `i >= k - 1` 时输出队头

求最大值：同理，维护单调递减队列（队尾元素 ≤ 当前值则出队）。

每个元素最多入队、出队一次，时间复杂度 O(N)。

## 参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
const int N = 1e6 + 10;

int a[N], q[N];

int main()
{
    int n, k;
    cin >> n >> k;
    
    for(int i = 0; i < n; i ++ ) cin >> a[i];
    int hh = 0, tt = -1;
    for(int i = 0; i < n; i ++ )
    {
        if(hh <= tt && q[hh] < i - k + 1) hh ++ ;
        while(hh <= tt && a[q[tt]] >= a[i]) tt -- ;
        q[ ++ tt ] = i;
        if(i >= k - 1) cout << a[q[hh]] << ' ';
    }
    puts("");
    
    hh = 0, tt = -1;
    for(int i = 0; i < n; i ++ )
    {
        if(hh <= tt && q[hh] < i - k + 1) hh ++ ;
        while(hh <= tt && a[q[tt]] <= a[i]) tt -- ;
        q[ ++ tt ] = i;
        if(i >= k - 1) cout << a[q[hh]] << ' ';
    }
    puts("");
    
    return 0;
}
```
