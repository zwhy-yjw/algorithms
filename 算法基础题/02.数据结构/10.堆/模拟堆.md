# 模拟堆

## 题目描述

维护一个集合，初始时集合为空，支持如下几种操作：

- `I x`，插入一个数 x
- `PM`，输出当前集合中的最小值
- `DM`，删除当前集合中的最小值（数据保证此时的最小值唯一）
- `D k`，删除第 k 个插入的数
- `C k x`，修改第 k 个插入的数，将其变为 x

现在要进行 N 次操作，对于所有第 2 个操作（PM），输出当前集合中的最小值。

## 输入格式

第一行包含整数 N。

接下来 N 行，每行包含一个操作指令，操作指令为 `I x`，`PM`，`DM`，`D k` 或 `C k x` 中的一种。

## 输出格式

对于每个 `PM` 操作，输出当前集合中的最小值。

每个结果占一行。

## 数据范围

1 ≤ N ≤ 10^5

所有输入的数不超过 10^9

## 输入样例

```
8
I -10
PM
I -10
D 1
C 2 8
I 6
PM
DM
```

## 输出样例

```
-10
6
```

## 思路

小根堆 + 双映射（支持删除/修改第 k 个插入的数）：

- `h[N]`：堆数组（1 下标，小根堆）
- `ph[i]`：第 i 个插入的数在堆中的下标
- `hp[k]`：堆中下标 k 对应的插入序号（ph 的反向映射）
- `sz`：堆大小
- `j`：插入计数（第几个插入的）

- **heap_swap(a, b)**：交换堆中两个位置，同时维护 ph 和 hp（三对交换）
- **down/up**：下沉/上浮（用 heap_swap 而非直接 swap）
- `D k`：先 `k = ph[k]` 定位，交换到末尾，删掉，再 down+up
- `C k x`：`k = ph[k]`，改值，down+up

## 参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
const int N = 100010;

int m;
int h[N];
int ph[N], hp[N];
int sz;

void heap_swap(int a, int b)
{
    swap(ph[hp[a]], ph[hp[b]]);
    swap(hp[a], hp[b]);
    swap(h[a], h[b]);
}

void down(int u)
{
    int t = u;
    if(u * 2 <= sz && h[u * 2] < h[t]) t = u * 2;
    if(u * 2 + 1 <= sz && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if(t != u)
    {
        heap_swap(u, t);
        down(t);
    }
}

void up(int u)
{
    while(u / 2 && h[u / 2] > h[u]) 
    {
        heap_swap(u, u / 2);
        u >>= 1; 
    }
}

int main()
{
    cin >> m;
    int k, x;
    int j = 0;
    string cmd;
    while (m -- )
    {
        cin >> cmd;
        if(cmd == "I")
        {
            cin >> x;
            sz ++ ;
            j ++ ;
            ph[j] = sz;
            hp[sz] = j;
            h[sz] = x;
            up(sz);
        }
        else if(cmd == "PM") cout << h[1] << endl;
        else if(cmd == "DM")
        {
            heap_swap(1, sz);
            sz -- ;
            down(1);
        }
        else if(cmd == "D")
        {
            cin >> k;
            k = ph[k];
            heap_swap(k, sz);
            sz -- ;
            down(k), up(k);
        }
        else if(cmd == "C")
        {
            cin >> k >> x;
            k = ph[k];
            h[k] = x;
            down(k), up(k);
        }
    }
    return 0;
}
```
